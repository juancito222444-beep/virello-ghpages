# STUDIO DE ANTO

Este es el proyecto de [STUDIO DE ANTO](studio-de-anto/README.md): una oficina 3D de agentes con ANTO como Director, conversación e **IA en la nube mediante Gemini o Groq**. No descarga ni ejecuta modelos locales.

**1.8.0 · estudio en expansión:** cuatro salas que se desbloquean con el progreso
del proyecto y se añaden únicamente con tu autorización. Conserva las mejoras
de conversaciones, Director y rendimiento.
[Instrucciones de esta entrega](studio-de-anto/docs/EXPANSION.md).

La carpeta de la copia de trabajo de Codex es `/workspace/estudio-de-anto`.
El código de la aplicación está en `studio-de-anto/`: `backend/`, `frontend/`,
`scripts/`, `tests/` y `docs/`. Se conservaron sus rutas internas y el historial
de Git. Esta ruta no cambia ni renombra la carpeta del Codespace del propietario.
El `index.html` de la raíz pertenece al antiguo sitio Virello de ropa;
no es Studio de Anto. Las instrucciones para futuras sesiones están en
[AGENTS.md](AGENTS.md).

1. Abre el Codespace de esta rama y espera la instalación.
2. En **Puertos**, abre **8765** con visibilidad **Privada**.
3. En **Configuración**, pega la clave y pulsa **Guardar clave y conectar**.
4. Vuelve a **Oficina** y conversa. Puedes cambiar o eliminar la clave desde la misma pantalla.

La clave se guarda en un archivo privado del servidor y nunca se devuelve al navegador ni se incluye en Git o los ZIP de entrega. Los secretos de Codespaces siguen siendo una alternativa.

Para volver a usarlo basta con reabrir el mismo Codespace. Las cuotas gratuitas dependen del proveedor y de tu cuenta; Codespaces tiene límites separados. No se promete uso ilimitado ni acceso gratuito a GPT de OpenAI.

Guías: [aplicación](studio-de-anto/README.md), [Codespaces](studio-de-anto/docs/CODESPACES.md), [actualizaciones](studio-de-anto/docs/ACTUALIZACIONES.md) y [validación](studio-de-anto/docs/VALIDACION.md).
