# Qué mejoró

1. **Mundo 3D:** materiales de plástico, sombras, iluminación, mobiliario detallado y personajes de bloques articulados.
2. **Interacción:** selección, clic para caminar, destinos escritorio/reunión, saludo y cámara giratoria. Las acciones visuales se distinguen de la actividad de IA.
3. **APIs:** Ollama como opción principal; LM Studio/llama.cpp como alternativa compatible. Prueba explícita de inferencia con modelo, proveedor, respuesta y tiempo.
4. **Memoria controlada:** valorar y guardar correcciones por proyecto/agente, con posibilidad de borrarlas. Esto mejora el contexto, no reentrena el modelo.
5. **GitHub:** configuración de Codespaces incluida; falta subir el código y probar el Codespace real. No se ha publicado nada automáticamente.
6. **Fiabilidad:** eventos de estados terminales, procedencia de resultados y cancelación de exportaciones sin anunciar archivos inexistentes.

La API oficial de GPT de OpenAI no se entrega como gratuita. La aplicación sigue sin requerir APIs de pago ni tarjeta bancaria para uso local.
